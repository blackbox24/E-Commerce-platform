# E-COMMERENCE PLATFORM

E-Commerce platform with cart and payment gateway integration.

## Requirements

- JWT authentication of sign up and login users
- CRUD operations
- Add and remove items from the cart
- View and search for products
- Ability of users to checkout and pay for products
- Integration of Payment gateway
- Data models

## Additional Requirements

- Use html /css and any templating engine like Jinga or EJS
- Interact with the API's using POSTMAN
